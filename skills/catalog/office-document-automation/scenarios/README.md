# Office Automation Scenarios

- XLSX generation with formulas/styles/freeze panes; package reopens and representative formulas reconcile.
- DOCX with section breaks, tables and images; no missing relationship parts.
- PPTX with long text; bounding-box/overflow review required before acceptance.
- Native Office PDF export; produced PDF must reopen and match expected page/slide count.
- 32-bit Office on 64-bit Windows; architecture-sensitive native integration is detected, not guessed.
- Modal prompt/protected view; automation times out safely and does not weaken Trust Center.
- User already has Office open; owned automation session closes without killing user sessions.
- External links/macros exist; no automatic refresh or enablement occurs.
