# Project Brain Scenarios

- New fact with source/date enters as active with confidence.
- Newer authoritative fact conflicts: preserve both and supersede/dispute explicitly.
- Same entity with alias/case change: map to canonical entity rather than duplicate.
- Analysis insight without sufficient evidence: keep in report, do not promote to fact.
- Decision changes later: old decision remains with superseded link.
- Old document imported after newer facts: recorded time differs from effective/source time and does not overwrite reality.
- Sensitive transient chat: admission gate rejects unnecessary storage.
- Agent starts a new session: project state is reconstructed from index + active facts + recent decisions, not from raw chat history.
